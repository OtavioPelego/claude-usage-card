Consumo no Claude Code

Atualizado em · dados só deste computador

Tokens = entrada + saída de cada linha do transcript do Claude Code (sem cache; uma resposta aparece em várias linhas e todas contam) — uma estimativa da conta do painel original, não uma cópia garantida. Mensagens = linhas de mensagem do usuário e do assistente. Sessões = conversas distintas. O Claude Code apaga transcripts antigos depois de um tempo, então o histórico começa no que ainda existia na primeira vez que o script rodou. Livros: ≈ 1,33 token por palavra (estimativa).
